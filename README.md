## **概要**

本サイトは、**模写案件**です。

デザインは既存デザインを用い、**HTML / CSS / JavaScript を用いたフロントエンド実装のみ**を行っています。

---

## **担当範囲**

- コーディング（HTML / CSS / JavaScript）
- レスポンシブ対応
- ハンバーガーメニュー実装

※ **デザイン制作は担当外**とし、デザイン支給で制作しています。

---

## **案件詳細**

- 依頼内容：以下のページの作成。
・トップページ
・Productsページ
・Products詳細ページ（16ページ）
・Aboutページ
・Companyページ
- 納期：7日
- 予算：5万円
- 基本要件：指定のコンテンツ幅。商品はPCで4列、SPで2列。Google Mapの挿入。Contactクリックでメール起動。

## **制作の目的**

- デザインカンプを正確に再現するコーディング力の証明
- 静的サイトにおける実装力の可視化

---

## **使用技術**

- HTML5
- CSS3
- JavaScript（ES6）
    - ハンバーガーメニュー実装

---

## **実装時に意識したポイント**

- SCSSのファイルをページごとに分割し、保守性の高さを担保
- 画像はサイト軽量化のためWebPに変換して使用
